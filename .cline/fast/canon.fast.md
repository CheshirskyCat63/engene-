# canon.fast

canon read policy:
- canon is second-line context, not first-line context
- first read .cline/fast and memory-bank
- then open only one relevant grouped canon file

group routing:
- 10 arch constitution
- 20 runtime entrypoints
- 30 ownership dependency
- 40 simulation laws
- 50 content perf budgets
- 60 phases reports
- 70 contracts edgecases

use canon when:
- architecture changes
- runtime split changes
- ownership changes
- dependency changes
- contract changes
- code/doc mismatch appears

skip canon when:
- local compile fix
- local path fix
- local import fix
- focused test fix
- obvious local bugfix with no boundary impact
