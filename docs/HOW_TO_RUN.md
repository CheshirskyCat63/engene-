# How to Run ENGENE (Phase 0 canonical)

## Canonical commands
```bash
cargo run --bin engene_test
cargo run --bin engene_game
cargo run --bin engene_sdk
cargo run --bin engene_headless -- --months 12
```

## Optional helpers
- `./run_game.ps1`
- `./run_sdk.ps1`

## Notes
- Packaged `.exe` artifacts are optional distribution outputs, not canonical dev entrypoints.
- Do not use quarantined legacy artifacts for normal run paths.
